# Soother - Mental Health Support App

Soother is a compassionate web application designed to provide emotional support and well-being resources to users experiencing mood changes and depression.

## Features

- **Music Therapy**: Curated playlists to boost your mood
- **Meditation & Breathing**: Guided breathing exercises and meditation sessions
- **Mood-Lifting Memes**: Positive content to bring a smile to your face
- **Mood Support Chat**: Interactive chatbot for emotional support
- **Community Connection**: Connect with others who understand your experiences
- **Dark Mode Support**: Comfortable viewing experience day or night

## Technology Stack

- React
- TypeScript
- Material-UI (MUI)
- React Router
- Context API for state management

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm start
```
